# Support

> Traditional Chinese reference: [SUPPORT.zh-TW.md](SUPPORT.zh-TW.md)

## Where To Ask

- Bugs, regressions, broken examples, or verification failures: open a GitHub issue.
- Documentation drift, unclear wording, or misleading examples: open a GitHub issue.
- Feature ideas or workflow improvements: open a GitHub issue with the problem you are trying to solve.
- Security concerns: follow [SECURITY.md](SECURITY.md) and use a private path only.
- General usage questions: if GitHub Discussions is enabled, use Discussions; otherwise open an issue and prefix the title with `[Question]`.

## Before Opening An Issue

- Explain what you expected and what happened instead.
- Link the affected files, prompts, templates, or examples.
- Include your ZeroSpec version, branch, or commit when relevant.
- Keep scope tight. One issue should describe one actionable problem.

## Language

English and Traditional Chinese are both acceptable.

## Response Expectations

ZeroSpec is maintained on a best-effort basis. Response time depends on scope, clarity, and maintainer availability.
