# Optional Implementation Bridge

> This retired bridge is retained as a migration example. It is **not** a ZeroSpec core Prompt Pack and is not loaded by the Router Skill.

For complex implementation work, use the target project's own planning workflow. Before coding, identify affected modules and contract owners; at task completion, state whether an existing narrative SPEC, a machine-verifiable contract, or neither needs an update and why.

This separation keeps ZeroSpec at Layer 0: context readiness and documentation governance, not execution orchestration.
